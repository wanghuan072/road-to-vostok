# Road To Vostok Guide

Unofficial survival companion for **[Road to Vostok](https://store.steampowered.com/app/1963610/Road_to_Vostok/)** — a hard-edged, open-world survival game set along the Russia–Finland border. The live site is **[roadtovostok.org](https://roadtovostok.org/)**.

This README describes the **game**, what you will find on the guide, and **every page linked from the site header and footer** (English URLs; other languages use the same paths with a locale prefix, e.g. `https://roadtovostok.org/zh/getting-started`).

---

## About the game

**Road to Vostok** is a survival experience focused on **scavenging, travel, gunplay, and tension** in a fictional border region inspired by real geography and Cold War–era atmosphere. You move between shelters and dangerous ground, manage **gear, medical supplies, and ammunition**, and push toward objectives tied to the wider journey toward **Vostok**.

The game has been available in **demo** form and evolves through **Steam Early Access**; builds, balance, and map content can change. Always **cross-check** anything you read here with what you see in your installed version.

---

## What makes it stand out

- **Border-zone survival**: harsh weather, limited resources, and hostile ground rather than arcade pacing.
- **Ballistics and loadouts**: weapons, calibers, and equipment matter; the wiki-style tables on the site help compare items at a glance.
- **Large overworld + focused maps**: a world overview for orientation, plus detailed **raster maps** for key locations (village, highway, school, and more).
- **Tasks and NPCs**: journal-style progression and characters you meet in the world; the site summarizes routes and links without replacing the in-game journal.
- **Community mods**: optional loaders and player-made content; the site lists curated mod pages separately from vanilla gameplay.

---

## Using this guide

The site is a **reference and reading companion**, not an official source. Use it to:

- **Plan routes** (maps, tasks, NPC locations).
- **Compare gear** (weapons, ammunition, fishing, gathering tables).
- **Read long-form guides** (minefields, geography, strategy articles).
- **Track high-level roadmap context** (Steam news, official site links — still verify on [Steam](https://store.steampowered.com/app/1963610/Road_to_Vostok/) and [roadtovostok.com](https://www.roadtovostok.com/game)).

## Frequently asked questions

**Is this an official site?**  
No. It is an independent guide and database. For authoritative announcements, use the developer’s channels and Steam.

**Will numbers (damage, prices, stacks) match my game?**  
Maybe not exactly. Early Access patches change data; treat tables as **orientation**, not guarantees.

**Do I need JavaScript enabled?**  
Yes, for the full interactive experience (maps, routing, and localized URLs).

**Which languages are supported on roadtovostok.org?**  
English (default, no prefix), plus Chinese, German, Russian, Finnish, and French — same paths with a `/{locale}/` prefix where applicable.

**Where do maps come from?**  
The interactive overview uses official-style artwork; regional and detail pages combine site copy with map assets. Always verify critical positions in-game.

## Optional: run the site locally

The web app lives in the `roadtovostok-web` directory of this repository.

```sh
cd roadtovostok-web
npm install
npm run dev
```

Production build: `npm run build` (includes sitemap generation). For tooling details, see the Vite and Vue documentation linked from the upstream templates if needed.
